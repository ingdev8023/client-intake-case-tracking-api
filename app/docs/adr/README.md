## ADR

An architecture decision record (ADR) is a document that captures an important architectural decision made along with its context and consequences.

### When to write an ADR

We want to create an ADR to explain the decisions made for the system that started as just an API and now is production ready system, also to keep track of the 'why' of what we are doing.

### Our file name and number convention:

 - The name has ADR at the beginning and a code number of 3 digits.
